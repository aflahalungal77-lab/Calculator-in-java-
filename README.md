# Calculator-in-java-

A simple and user-friendly **Calculator Application** built using **Java Swing**.

## Features

* ➕ Addition
* ➖ Subtraction
* ✖ Multiplication
* ➗ Division
* 🔢 Decimal Numbers
* ⌫ Backspace Button
* 🧹 Clear All (AC)
* 🎨 Clean GUI Design

## Technologies Used

* Java
* Swing
* AWT
